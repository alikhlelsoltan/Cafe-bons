# Cafe Bons - Smart Menu (سمارت مينيو)
**Multi-Tenant Cafe & Smart Digital Menu Platform for Android (com.smartmenu.cafeapp)**

---

## 🌟 Overview (نظرة عامة)
منصة SaaS متكاملة متعددة المستأجرين (Multi-tenant) لإدارة الكافيهات وقوائم الطعام الذكية عبر مسح رمز الاستجابة السريعة (QR Code) للطاولات.
مبنية بالكامل بنظام **Android Jetpack Compose** ومربوطة بقاعدة بيانات **Firebase Firestore** لمشروع `cafe-bons`.

---

## 📱 Core Features (الميزات الرئيسية)

### 1. صفحة ومسار الزبائن (Customer Menu View & QR Ordering)
- استعراض قائمة المشروبات والمأكولات الحية مباشرة بعد مسح كود الطاولة.
- تصفية المأكولات حسب الأقسام (ساخن، بارد، حلويات، قهوة مختصة، شيشة).
- إضافة المواد إلى السلة مع تحديد الكميات وكتابة ملاحظات الزبون (مثل: سكر خفيف، بدون ثلج).
- احتساب ضريبة القيمة المضافة والإجمالي فورياً وإرسال الطلب مباشرة إلى شاشة الكاشير والمطبخ.
- عرض بيانات شبكة الواي فاي للزبائن ورسالة الترحيب الخاصة بالكافيه.

### 2. تسجيل الكافيهات ولوحة المشرف العام (Multi-Tenant & Super Admin)
- تسجيل كافيه جديد باسم ومعرف فريد (Slug) وكلمة مرور.
- اعتماد حالة الحساب الجديد `pending` لحين مراجعته وموافقته من الأدمن.
- لوحة المشرف العام (Super Admin) للاطلاع على طلبات الانضمام والموافقة الفورية وتفعيل لوحة التحكم.

### 3. لوحة تحكم صاحب الكافيه (Owner Dashboard)
- إحصائيات حية: مبيعات اليوم، الطلبات النشطة، إجمالي الطاولات والمواد.
- **إدارة الأقسام والمنتجات:** إضافة، تعديل، حذف، وتغيير حالة التوفر في المخزن (متوفر / غير متوفر).
- **باركود الطاولات وتوليد PDF:** توليد رمز QR فريد لكل طاولة وطباعة الملصقات أو تصديرها كملف PDF.
- **الطلبات والتحضير والكاشير:** متابعة سير الطلبات من "جديد" إلى "قيد التحضير" و"جاهز للتقديم" و"تم الحساب"، مع طباعة بون الطلب الحراري (Print Bon / Receipt).
- **إعدادات الكافيه:** تعديل اسم الكافيه، العملة، نسبة الضريبة، رسالة الترحيب، وبيانات الواي فاي.

## 🛠️ Tech Stack & Setup
- **OS / Platform:** Android (Kotlin DSL, SDK 36, MinSdk 26)
- **UI Toolkit:** Jetpack Compose + Material Design 3 (M3) Dark Luxe Theme
- **Package Name:** `com.smartmenu.cafeapp`
- **Backend & Cloud:** Firebase Firestore (`cafe-bons` project)
- **Architecture:** MVVM + Clean Repository Pattern + StateFlow
